GUSTO CAPITAL WEBSITE STARTER

Files
- index.html: homepage
- investments.html: investment themes page
- grants.html: grants and funding page
- about.html: company/about page
- contact.html: contact page with demonstration form
- assets/styles.css: shared responsive styling
- assets/script.js: mobile navigation, modal and calculator behavior

Preview
Open index.html in a browser. Keep the assets folder beside the HTML files.

Publish
Upload the entire gusto-capital folder contents to your hosting public_html folder (Hostinger) or repository root (GitHub Pages/Netlify). Do not upload only index.html.

Before launch
1. Replace stock photos with licensed brand imagery if desired.
2. Add verified legal company details and real contact information.
3. Connect the contact form to a secure form provider/backend.
4. Implement real authentication before offering investor or applicant logins.
5. Add privacy policy, terms and jurisdiction-appropriate disclosures.
6. Only publish factual metrics, regulatory status, investment performance, rates, returns or grant amounts that are independently verified and legally approved.
7. The calculator is educational only and does not represent an investment offer or guaranteed return.

This is a front-end starter, not a production financial platform. It does not store or transmit application, identity, banking or investor data.
